Data Model Insights from Sources

  • Asset Connectivity: Assets such as A32B, J100, and K100 are physically connected on Willow Springs Dr and terminate at HDV-110 [1-4].
  • Grid References: Each grid reference (e.g., #54 #6-4 #40) corresponds to a specific map sheet, which can be linked as a feature attribute in ArcEarth [3, 5, 6].
  • Signal Standards: Units consistently operate at 38V [3, 7, 8]. Most FLEX MAX 321e units use a standardized config code (e.g., 46 04 21.5 21.5) that defines the gain settings [1, 9, 10].
  • Status Metadata: The model includes a Status field to account for units marked as "NOT BUILT" in later fielding reports like 549-434.pdf [11].
  • Port Mapping: The Connector_Ref (Port) mapping (C2, C5, C9) allows Survey123 to pre-populate which cable path the technician should verify [2, 7, 12].
