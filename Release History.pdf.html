As new versions are released, this document will highlight any updates in those versions. Release 2 (November 8, 2023) This is the second release of the Cityworks Connector for GeoEvent Server. The Cityworks Connectors are now out of Beta and can be used in production environments. This version is compatible with ArcGIS GeoEvent Server 10.6 and later. Release 1d (BETA – February 5, 2020) This is the fourth Beta release of the Cityworks Connectors for GeoEvent Server. This version is compatible with ArcGIS GeoEvent Server 10.4 through 10.8. This release is currently in Beta and should not be used in a production setting. Please report all issues and enhancement requests to geoevent@esri.com. Release 1c (BETA - October 31, 2019) This is the third Beta release of the Cityworks Connectors for GeoEvent Server. This version is compatible with ArcGIS GeoEvent Server 10.4 through 10.7.1. This release is currently in Beta and should not be used in a production setting. Please report all issues and enhancement requests to geoevent@esri.com. Release 1b (BETA - October 23, 2019) This is the second Beta release of the Cityworks Connectors for GeoEvent Server. This version is compatible with ArcGIS GeoEvent Server 10.4 through 10.7.1. This release is currently in Beta and should not be used in a production setting. Please report all issues and enhancement requests to geoevent@esri.com. Release 1a (BETA - October 14, 2019) This is the first Beta release of the Cityworks Connectors for GeoEvent Server. This version is compatible with ArcGIS GeoEvent Server 10.4 through 10.7.1. This release is currently in Beta and should not be used in a production setting. Please report all issues and enhancement requests to geoevent@esri.com.
