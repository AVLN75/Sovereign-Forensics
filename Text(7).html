#!/usr/bin/env python3

import subprocess

import ipaddress

def scan_network(network_prefix):

"""Scans a network for active hosts.

Args:

network_prefix (str): The network prefix in CIDR notation (e.g., "192.168.1.0/24").

Returns:

list: A list of active IP addresses found on the network.

"""

active_hosts = []

try:

network = ipaddress.ip_network(network_prefix, strict=False)

for ip in network.hosts():

ip_str = str(ip)

Use ping to check if the host is alive. Adjust parameters as needed.

-c 1: Send only one ping packet

-W 1: Wait at most 1 second for a response

ping_command = f"ping -c 1 -W 1 {ip_str}"

process = subprocess.Popen(ping_command, shell=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE)

stdout, stderr = process.communicate()

if process.returncode == 0:

active_hosts.append(ip_str)

print(f"Host {ip_str} is active.")

except ValueError:

print(f"Error: Invalid network prefix '{network_prefix}'.")

return active_hosts

def get_device_info(ip_address):

"""Attempts to get basic information about a device using ARP.

Args:

ip_address (str): The IP address of the device.

Returns:

dict: A dictionary containing 'ip' and 'mac' address if found, otherwise None.

"""

arp_command = f"arp -n {ip_address}"

process = subprocess.Popen(arp_command, shell=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE)

stdout, stderr = process.communicate()

for line in stdout.decode().splitlines():

parts = line.split()

if len(parts) >= 2 and parts[0] == ip_address:

return {"ip": parts[0], "mac": parts[1]}

return None

def main():

"""Main function to scan the network and import device information."""

network_prefix = input("Enter the network prefix to scan (e.g., 192.168.1.0/24): ")

active_ips = scan_network(network_prefix)

if active_ips:

print("\nScanning active hosts for device information (ARP):")

devices = []

for ip in active_ips:

device_info = get_device_info(ip)

if device_info:

devices.append(device_info)

print(f" IP: {device_info['ip']}, MAC: {device_info['mac']}")

else:

print(f" IP: {ip}, MAC: Not found (ARP entry might not exist).")

if devices:

print("\nConnected Devices:")

for device in devices:

print(f" IP Address: {device['ip']}, MAC Address: {device['mac']}")

else:

print("\nNo devices found on the network (ARP entries not available).")

else:

print("\nNo active hosts found on the specified network.")

if name == "main":

main()

Explanation:

#!/usr/bin/env python3: Shebang line, specifies the interpreter for the script.

import subprocess: Imports the subprocess module to run external commands like ping and arp.

import ipaddress: Imports the ipaddress module for working with IP network addresses.

scan_network(network_prefix) function:

Takes the network prefix (e.g., "192.168.1.0/24") as input.

Uses ipaddress.ip_network() to generate a list of all possible host IP addresses within the given network.

Iterates through each IP address.

Uses subprocess.Popen() to execute the ping command with the following options:

-c 1: Sends only one ICMP echo request (ping packet).

-W 1: Sets a timeout of 1 second for a response. This makes the scan faster.

Checks the process.returncode. A return code of 0 usually indicates success (the host responded to the ping).

If a host is active, its IP address is added to the active_hosts list and printed.

Handles potential ValueError if the provided network_prefix is invalid.

Returns the list of active IP addresses.

get_device_info(ip_address) function:

Takes an IP address as input.

Uses subprocess.Popen() to execute the arp -n command. The arp command displays the ARP cache, which maps IP addresses to MAC addresses on the local network. The -n flag prevents DNS lookups, making it faster.

Parses the output of the arp command. It looks for a line where the first part matches the given ip_address.

If a matching entry is found, it extracts the IP and MAC address and returns them in a dictionary.

Returns None if no ARP entry is found for the given IP address. This can happen if the device is not actively communicating or if the ARP entry has expired.

main() function:

Prompts the user to enter the network prefix to scan.

Calls scan_network() to get a list of active IP addresses.

If active IPs are found:

Iterates through the active_ips list.

Calls get_device_info() for each active IP to try and retrieve its MAC address.

Prints the IP and MAC address if found.

Keeps a list of devices with both IP and MAC addresses.

Finally, prints a summary of the connected devices found.

If no active hosts are found, it prints a corresponding message.

if name == "main":: Ensures that the main() function is called only when the script is executed directly.

How to Use:

Save the script: Save the code to a file, for example, network_scanner.py.

Make it executable: Open your Linux terminal and run:

chmod +x network_scanner.py

Run the script: Execute the script with:

./network_scanner.py

Enter the network prefix: When prompted, enter the network prefix of your local network. For example, if your router's IP is typically 192.168.1.1, your network prefix is likely 192.168.1.0/24.

Important Considerations and Potential Improvements:

Permissions: You might need sudo privileges to run ping effectively on some systems. If you encounter permission errors, try running the script with sudo:

sudo ./network_scanner.py

ARP Limitations: ARP only works within the same local network segment (Layer 2). You won't be able to get MAC addresses of devices on different subnets using this method.

Firewalls: Firewalls on target devices might block ICMP (ping) requests, causing the scanner to miss active hosts.

Speed: For larger networks, this script might take some time to complete as it pings each possible IP address. You could explore asynchronous methods (like using the asyncio library) or multithreading/multiprocessing to speed up the scanning process.

More Information: You could extend this script to gather more information about the devices, such as:

Hostname: Using tools like nmblookup (for NetBIOS names) or performing reverse DNS lookups.

Open Ports and Services: Using tools like nmap (which is a more powerful network scanning tool but requires installation).

Operating System Fingerprinting: This is a more advanced technique and often involves analyzing network responses.

Error Handling: You could add more robust error handling for network issues and command execution failures.

Output Formatting: You could format the output in a more structured way (e.g., using CSV or JSON).

User Interface: For a more user-friendly experience, you could consider building a simple graphical user interface (GUI) using libraries like Tkinter or PyQt.

This script provides a basic foundation for network scanning and device discovery on a Linux system. You can expand upon it based on your specific needs and the level of detail you require. Remember that network scanning should be done responsibly and ethically, and you should only scan networks that you have permission to access.
